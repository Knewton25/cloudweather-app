Cloud Weather App 🌦️
A sleek, modern React weather app that provides real-time weather updates for cities around the world. Built using React + Vite, this app showcases weather conditions, temperature, and more in a user-friendly interface.

🚀 Features
🌡️ Real-time Weather Data: Get up-to-date weather information for any city.
🌎 Global Search: Search for weather updates in any location around the world.
⚡ Fast and Lightweight: Built with Vite for fast development and optimized performance.
🌥️ Weather Icons: Displays weather conditions using dynamic icons for better visualization.

🛠️ Technologies Used
React (Frontend)
Vite (Build tool)
OpenWeatherMap API (Weather data)
CSS/SCSS (Styling)
Axios (API requests)


# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh


🔧 Usage
Enter the name of a city in the search bar.
The app will display:
Current temperature
Weather condition (e.g., Clear, Rainy, Cloudy)
Humidity levels
Wind speed
